# Exercise_Note
My project to serve my life in health and programming

![Exercisenote1](https://github.com/kunanonsurasorn/Exercise_Note/blob/main/Exercisenote1.jpg)

I call it "Exercise Note" because I record my exercise activity after I exercised in the text file with the program. I has problem about Where should I record my exercise activity. I think I record in the text file because It can replace into many places. 

![Exercisenote2](https://github.com/kunanonsurasorn/Exercise_Note/blob/main/Exercisenote2.jpg)

In the first development, It was created with simple script including List and File Management. The file was run in Visual Studio Code and recorded my exercise activity in text file. I have used the program to record my exercise activity.

![Exercisenote3](https://github.com/kunanonsurasorn/Exercise_Note/blob/main/Exercisenote3.jpg)

In next week, I found mistake when I type my activity with my hand.(I typed "Aerobix" instead "Aerobic") I developed the graphical user interface with Tkinter. It can use Option Menu to select the exercise activity. 

![Exercisenote4](https://github.com/kunanonsurasorn/Exercise_Note/blob/main/Exercisenote4.jpg)

In the program, I can record day, month, year, exercise type with Option Menu and count of exercise time (minute) into the GUI. It has Start and Reset Button.

I think the program is not complete. It has a lot of something that It will improve in the future because I must use the program to record my exercise activity.
